# Lua Functions and Variables by Entity

> **Note:** EVERY function is called with the entity `e` as the first parameter.

## Entity: Caca
- `getPosition`
  - **Returns:** `x` `y` `z` 
- `setPosition`
  - **Parameters:** `x` `y` `z`
